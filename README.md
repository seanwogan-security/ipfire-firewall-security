# ipfire-firewall-security
A virtual cybersecurity lab created to configure, test and evaluate firewall security using IPFire.

# Lab Environment
IPFire Firewall
Attacker Machine
Victim Machine
VirtualBox
Private virtual network

# Rundown
The lab consisted of multiple virtual machines representing a firewall, attacker and victim system.
IPFire was used to control traffic between systems and test how different firewall rules affected network communication.

Firewall rules were configured and tested for services including SSH, ICMP & network communication between hosts. 
Testing was performed from an attacker system to determine whether configured firewall rules correctly allowed or blocked traffic.
